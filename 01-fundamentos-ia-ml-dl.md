# 01 - Fundamentos: IA x Machine Learning x Deep Learning

## Comparativo

| Conceito | O que é | Exemplo |
|---|---|---|
| **IA** | Qualquer sistema que simula inteligência, inclusive com regras fixas | Robô de xadrez com regras programadas à mão |
| **Machine Learning (ML)** | Aprende padrões a partir de dados | Prever qual produto vai faltar no estoque |
| **Deep Learning** | ML com redes neurais profundas; bom com imagem, voz e texto | Reconhecer o produto numa foto; ChatGPT/Claude |

## Pontos-chave

1. Todo ML é IA, mas nem toda IA é ML.
2. Todo Deep Learning é ML, mas nem todo ML é Deep Learning.
3. Quanto mais complexo e bagunçado o dado (texto, imagem), mais o Deep Learning se destaca.
4. Hierarquia: IA ⊃ ML ⊃ Deep Learning.

## Exercício

**Pergunta:** Um sistema que olha a foto de uma caixa e diz se a embalagem está avariada é IA, ML ou Deep Learning? Por quê?

É Deep Learning, porque irá analisar dados bagunçados(imagens), pois é aprendido padrões de milhares de fotos rotuladas como "boa","avaria", dentre outras.
Destacando-se em seu resultado, sem usar if para escrever condições.
